# 主题质量专项评估

日期：2026-10-22。评估对象为当前 nmf-v3：固定官方 584 条通信，移除完整实体名、部分人物姓名、英语缩写碎片，TF-IDF + NMF，默认 6 主题、nndsvda 初始化、seed 42。仅建模文本改变，原文和图端点保持不变。

## 先复现，再处理噪声

原模型在 4/6/8 主题关键词中包含 ve、ll；新增测试在旧实现上失败，增加英语缩写碎片停用词后通过。没有为获得更漂亮的主题而删除 near、vessels、许可编号或时间词：这些可能有调查意义，需由原文解释。v2 和 v3 的主题编号及计数不可直接等同，旧分析底稿与 topic-model-review.json 保留为历史快照。

## 扰动检查

复现命令：项目 Python 环境执行 `python scripts/review_topics.py`。机器可读结果及全部改变归属的消息 ID 见 [TOPIC_QUALITY_REVIEW.json](TOPIC_QUALITY_REVIEW.json)。每种主题数执行 21 组，共 63 组：3 个生产初始化种子、3 个随机初始化、移除 4 条重复正文、逐一移除 14 个观察日。

保持全量词表及 IDF，仅改变 NMF 的初始化或训练行；每个扰动模型投影回全部 584 条消息进行比较。这不是独立测试集准确率。使用最大余弦匹配对齐主题，ARI 不受标签排列影响；改变数按匹配后最大因子归属计算。无真实主题标签，不能称为准确率或通过率。63 组均未出现收敛警告。

## 对系统和分析的约束

界面明确提示对样本与初始化敏感、编号不是固定类别、需结合原文解释；API 导出的 limitation 保留同样边界。日期/主体筛选始终聚合固定模型，不能在每次筛选时偷偷重训。群体主题矩阵是关联通信，跨群消息可在两行出现；内部主题计数另见 [当前分析说明](CURRENT_ANALYSIS.md)。

本专项已完成噪声修复、扰动评估和代表原文阅读。没有依据将主题视为稳定真值分类；如后续任务需要自动分类准确率，应先获得独立标签和评价设计，不能继续调权直到结果看起来稳定。

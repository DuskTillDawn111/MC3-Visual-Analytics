# 3–5 分钟课程演示

> 历史短演示脚本，界面入口和布局已变化，不能替代正式课程材料。本轮按用户要求暂不制作课程材料；当前操作入口见 [README 两分钟上手](../README.md)，实现范围见 [最终项目验收](FINAL_PROJECT_AUDIT.md)。

## 0:00–0:35　交代数据与问题

打开工作台，说明是官方 VAST 2025 MC3 合成竞赛数据、故事发生在 2040 年。概览显示 584 条通信；通信投影只含 41 个实际参与者，不能与原图 72 实体、1,159 节点混淆。

本系统的问题是如何从通信模式进入关系、候选身份与事件证据，而不是展示一个预设嫌疑名单。

## 0:35–1:15　模式与真实联动

点击热力图或“密集时段”中的 10-05 10 时，看到 24 条通信。总览、图和消息同步变化。选一条连线，检查发送/接收方向、消息 ID 和完整英文原文。点击原文支撑的事件，再回到主体。

重置，点击异常提示 10-04 13 时。解释这里有 9 条消息，但其他日同小时中位数为 0；对基线的偏离比最高总量时段更突出。展开贡献与原始 ID，说明这只是探索提示。

## 1:15–2:00　群体结构和证据类型

重置后悬停节点，展示中心性和邻域；拖动、缩放网络。展开群体说明，展示成员与主题。选择社区，或勾选跨群桥梁。强调颜色是算法社区、大小是通信活动，不能解释为违法程度。

切换原始关系检查，筛选推断关联，展示虚线。点一个 Event/Relationship 节点，检查原始字段和 evidence_for。说明原图与通信投影的算法意义不同。

## 2:00–2:50　主体事件链

点击“探索 Nadia Conti”，显示 26 条直接通信和 15 个相关非通信事件。打开 Event_Assessment_329，再查 Event_Communication_330；沿消息与参与实体连接往返探索。

说明时间轴只是排序后的关联候选；事件由故事人物从通信推断，不能从排列得出因果或违法结论。

## 2:50–3:40　化名比较与不确定性

重置，在 Boss 的默认候选排名中对比前两名：约 35.16 与 34.63，差距很小。展开权重，调节时间或文本权重，观察贡献变化。打开支持消息、共享上下文与互发反证。

解释称呼启发式、样本量和共现环境；分数不是概率。保留多个候选，保存一条“不确定”的人工标记，并导出比较记录。

## 3:40–4:20　质量、可追溯与工程

打开质量检查：32 个事件缺少 timestamp、81 条通信无证据连接，原文仍保留。检查 2023 年的 Event_VesselMovement_1000；再说明 2040-10-15 的 Event_VesselMovement_944 是观察期外事件，两者没有被改写。

展示消息/证据 JSON 导出，再点击顶部“导出报告”：离线 HTML 中包含当前图表、筛选条件、完整消息与所选节点证据，可通过浏览器打印为 PDF。展示源 ZIP SHA-256、双平台测试结果和复现命令。结束于“每条分析线索都有原始 ID，不能替证据不足的问题给出确定答案”。

## 可替代操作

- 默认无候选：先重置日期/检索；候选比较需要双方在当前范围有消息。
- 图节点过多：选择主体和 1 跳，或使用社区筛选；原图显示截断提示时缩小范围。
- 证据阅读器位于页面下方：点击右下“证据已更新”提示定位。
- 不方便展示长英文：用消息 ID 和原文关键词定位，保留原文不做未经标注的翻译。
